01 — About

저를 소개합니다

배운 것을 눈에 보이는 결과물로 남기는 걸 좋아합니다. 지금까지 터미널에서 도는 4지선다 퀴즈 게임과, MAC 연산으로 패턴을 판별하는 Mini NPU 시뮬레이터를 외부 라이브러리 없이 파이썬 표준 라이브러리만으로 만들었습니다.

두 미션을 지나며 잘못된 입력을 어떻게 걸러 내는지, 부동소수점 비교가 왜 어긋나는지, 연산 횟수가 시간에 어떻게 반영되는지를 직접 재 보며 익혔습니다. 이번에는 그 관심을 브라우저로 옮겨, 사용자 이벤트 → 상태 변경 → 화면 갱신이 어떻게 이어지는지를 한 페이지 안에서 확인하고 있습니다.

  • 과정 Codyssey 입학연수 · 개발 입문
  • 관심 웹 프론트엔드, 데이터가 화면이 되는 과정
  • 다음 React 의 컴포넌트와 상태 관리
  • 원칙 왜 그렇게 했는지 설명할 수 있는 코드
