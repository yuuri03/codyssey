# 뮤지컬 퀴즈 게임

터미널에서 동작하는 4지선다 퀴즈 게임입니다.
Python 기본 문법과 클래스(객체 지향), JSON 파일 기반 데이터 영속성을 학습하기 위해 만들었습니다.

## 프로젝트 개요

메뉴에서 번호를 골라 퀴즈를 풀고, 직접 문제를 추가하고, 목록과 최고 점수를 확인하는
콘솔 프로그램입니다. 외부 라이브러리 없이 파이썬 표준 라이브러리(`json`, `os`)만 사용합니다.

프로그램을 종료했다가 다시 실행해도 추가한 퀴즈와 최고 점수가 그대로 남습니다.
모든 데이터는 프로젝트 루트의 `state.json` 에 UTF-8 로 저장됩니다.

- 개발 언어: Python 3.10 이상 (개발·검증 환경 3.13)
- 실행 방식: 터미널(콘솔)
- 외부 의존성: 없음

## 퀴즈 주제와 선정 이유

주제는 **뮤지컬**입니다.

- **정답이 하나로 떨어집니다.** 작곡가, 원작 소설, 대표 넘버, 시상식처럼
  취향이 아니라 사실로 확인되는 항목이 많아 4지선다 형식과 잘 맞습니다.
- **오답 선택지를 만들기 좋습니다.** 같은 범주 안에 비슷한 무게의 후보가 여럿 있어
  (예: 앤드루 로이드 웨버 / 스티븐 손드하임 / 클로드미셸 쇤베르크)
  찍어서 맞히기 어려운 문제를 구성할 수 있습니다.
- **문항 갈래를 나눌 수 있습니다.** 작곡가, 원작, 넘버, 시상식, 극장가처럼
  카테고리가 뚜렷해 문제를 늘려도 한쪽으로 치우치지 않습니다.

기본 문항은 10개이며, 게임 안에서 직접 추가할 수 있습니다.

## 실행 방법

```bash
python quiz_game.py
```

Windows 에서 `python` 이 잡히지 않으면 `py quiz_game.py` 로 실행합니다.

첫 실행에는 저장 파일이 없으므로 기본 퀴즈 10문항으로 시작하며,
아래와 같은 안내가 먼저 출력됩니다.

```
[안내] 저장된 데이터가 없습니다. 기본 퀴즈로 시작합니다.
```

두 번째 실행부터는 저장된 내용을 불러옵니다.

```
[알림] 저장된 데이터를 불러왔습니다. (퀴즈 11개, 최고 기록 11문제 정답)
```

## 기능 목록

메뉴에서 번호를 입력해 기능을 고릅니다.

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 퀴즈 풀기 | 등록된 퀴즈를 순서대로 출제하고 즉시 정답 여부를 알려줍니다. 다 풀면 맞힌 개수와 정답률을 보여주고, 최고 점수를 갱신하면 알려줍니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력받아 새 문항을 등록하고 곧바로 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 문항을 번호와 함께 한 줄씩 보여줍니다. |
| 4 | 점수 확인 | 지금까지의 최고 기록을 보여줍니다. 아직 풀지 않았으면 그 사실을 안내합니다. |
| 5 | 종료 | 현재 상태를 저장하고 프로그램을 끝냅니다. |

### 입력·예외 처리

숫자를 받는 모든 자리에서 아래를 처리하고, 안내 메시지를 띄운 뒤 다시 입력받습니다.

- 앞뒤 공백은 제거합니다. (`  4  ` → `4`)
- 빈 입력(그냥 Enter)
- 숫자로 바꿀 수 없는 값 (`abc`)
- 허용 범위 밖의 숫자 (메뉴에서 `9`, 정답 번호로 `0`)

그 밖에 아래 상황에서도 프로그램이 비정상 종료하지 않습니다.

- **Ctrl+C(KeyboardInterrupt), 입력 스트림 종료(EOFError)**
  안내 메시지를 출력하고 현재까지의 퀴즈·최고 점수를 저장한 뒤 종료합니다.
- **저장 파일이 없음** — 기본 퀴즈로 시작합니다.
- **저장 파일이 손상됨(JSON 파싱 실패)** — 안내 후 기본 퀴즈로 복구합니다.
- **일부 문항만 깨짐** — 깨진 문항 수를 알려주고 나머지는 그대로 불러옵니다.
- **읽기/쓰기 오류(OSError)** — 안내 메시지를 출력하고 게임은 계속 진행합니다.

## 파일 구조

저장소는 미션별 폴더로 나뉘어 있고, 이 미션은 `python-quiz-game/` 폴더입니다.

```
codyssey/                    # 저장소 루트
├── .gitignore               # state.json 등 추적 제외 규칙 (저장소 공통)
├── README.md                # 저장소 전체 안내
├── python-quiz-game/        # ← 이 미션
│   ├── quiz_game.py         # 프로그램 전체 (Quiz, QuizGame 클래스와 입력 헬퍼)
│   ├── state.json           # 퀴즈 목록과 최고 점수 저장 파일 (실행 시 자동 생성, git 추적 제외)
│   └── README.md            # 이 문서
└── mini-npu-simulator/      # 다른 미션
```

### `quiz_game.py` 구성

| 구분 | 이름 | 역할 |
| --- | --- | --- |
| 상수 | `TITLE`, `MENU_ITEMS`, `CHOICE_COUNT`, `STATE_FILE`, `DEFAULT_QUIZ_DATA` | 제목, 메뉴 정의, 선택지 개수(4), 저장 경로, 기본 문항 |
| 클래스 | `Quiz` | 문제 한 개(문제·선택지·정답)를 담고 검증·출력·채점·직렬화를 담당 |
| 클래스 | `QuizGame` | 퀴즈 목록과 최고 점수를 들고 메뉴 진행·저장·불러오기를 담당 |
| 함수 | `ask_int()`, `ask_text()`, `read_menu_choice()` | 잘못된 입력을 걸러 내는 공통 입력 헬퍼 |
| 함수 | `default_quizzes()` | 기본 문항 데이터를 `Quiz` 목록으로 변환 |
| 함수 | `main()`, `finish_early()` | 시작점과 중단 시 안전 종료 처리 |

`STATE_FILE` 은 `__file__`(소스 파일 위치) 기준으로 경로를 만듭니다.
그래서 어느 디렉터리에서 실행하든 항상 `quiz_game.py` 옆의
`python-quiz-game/state.json` 을 가리킵니다.

## 데이터 파일 설명 (`state.json`)

- **경로**: 이 프로젝트 폴더의 루트 `python-quiz-game/state.json`
  (`quiz_game.py` 와 같은 위치)
- **인코딩**: UTF-8 (`ensure_ascii=False` 로 한글을 그대로 저장)
- **역할**: 퀴즈 목록과 최고 점수를 담아 프로그램을 껐다 켜도 유지되게 합니다.
- **생성 시점**: 첫 실행에는 없으며, 퀴즈를 추가하거나 최고 점수가 갱신되거나
  프로그램을 종료할 때 만들어집니다.
- **git 추적**: `.gitignore` 에 등록되어 저장소에는 올라가지 않습니다.
  사용자마다 추가한 문항과 점수가 다르기 때문입니다.

### 스키마

| 키 | 타입 | 설명 |
| --- | --- | --- |
| `quizzes` | 배열 | 퀴즈 목록 |
| `quizzes[].question` | 문자열 | 문제 내용 (빈 값 불가) |
| `quizzes[].choices` | 문자열 배열 | 선택지 4개 (빈 값 불가) |
| `quizzes[].answer` | 정수 | 정답 번호 `1`~`4` |
| `best_score` | 정수 또는 `null` | 최고 기록(맞힌 문제 수). 아직 풀지 않았으면 `null` |

`best_score` 를 `0` 이 아니라 `null` 로 두는 이유는,
**아직 한 번도 풀지 않은 상태**와 **풀었지만 한 문제도 못 맞힌 기록(0점)** 을 구분하기 위해서입니다.

### 예시

```json
{
  "quizzes": [
    {
      "question": "뮤지컬 「오페라의 유령」의 음악을 작곡한 인물은?",
      "choices": ["스티븐 손드하임", "앤드루 로이드 웨버", "클로드미셸 쇤베르크", "프랭크 와일드혼"],
      "answer": 2
    }
  ],
  "best_score": 9
}
```

저장 파일을 지우면 기본 퀴즈 10문항 상태로 되돌아갑니다.
